# 交付后的手动检查

根据 2026-11-10 用户更正 U2，以下实机和真实云端检查由用户后续手动完成。本次没有执行，不标记为通过；无需模拟器。

1. 安装 Windows x64 安装包或 Android ARM64 APK，打开 Granite。首版没有预置书籍或虚构阅读统计。
2. 在「设置 → 书库」选择自己的书库文件夹；Android 使用系统目录授权。导入 EPUB、PDF、TXT、MOBI，分别打开、跳转和添加书签，退出后重新打开检查位置。
3. 新建 Markdown 笔记，添加附件与标签，切换笔记和重启后检查内容。导出有附件的笔记时会生成含 Markdown 与实际附件的 ZIP。
4. 在可写 PDF 中添加高亮、下划线、文本批注和墨迹；等待写回完成，用其他 PDF 阅读器检查。若文件在外部被修改，Granite 应保留外部版本并报告写回冲突；可将修改版本重新导入为新书。
5. 导出完整备份并试恢复。备份保留原文件与元数据；云凭证和设备目录授权不随备份导出。恢复存储配置时需要重新授权并验证读写。
6. 如需云同步，在「同步与存储」配置 WebDAV 或 S3-compatible，只在应用内输入密码/密钥。默认策略是「仅元数据」；测试书籍文件上传下载时选择「全量同步」或相应的指定/按需策略。另一设备须使用同一 Provider、账户和同步前缀，但各自选择本地目录。
7. 检查多根目录、目录重新授权、系统分享、系统返回、窗口恢复和离线场景。解除目录关联应保留原件；删除书籍则按确认框说明传播删除墓碑。

完整缓冲操作的文件大小上限为 512 MiB；原生 PDF 浏览采用范围读取，但标注编辑仍需要完整缓冲。EPUB、TXT、MOBI 的解析器也需要完整输入。运行内存、启动时间、触控及不同云服务的实际表现请以本次手测为准。

本地 Android 签名材料位于忽略目录 `private/signing`；请妥善备份以保留后续更新的签名身份。该目录和密码不会提交到仓库。
