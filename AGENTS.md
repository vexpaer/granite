# Granite engineering

Use PowerShell 7 (`pwsh`) on Windows. Follow `granite 规格书/Granite 规格书.md`; confirmed requirements take priority. All spawned subagents must use `group/ds` as requested. All dependency installation, builds, tests and CI/CD run on GitHub-hosted Actions runners. Keep the local project as a source/Git checkout with its protected signing backup; do not install local toolchains, dependencies, browsers or caches. Do not use Android emulators or virtual devices. Never publish a release with known data safety, startup or core reading failures. Never commit credentials, signing material, personal books, local library paths or test artifacts containing them.

Shared model: src/types.ts. Native bridge and ownership: docs/implementation-contract.md. Traceability: docs/acceptance.md. Run the minimal frontend unit/type checks and native test/check/build checks in GitHub Actions before integration; local checks are limited to Git and source inspection. Preserve external library originals; root unlink is never remote delete. No fake UI data or success states.

User update U3 (2026-11-11) supersedes U2 and older local-validation requirements: use only simple tests that GitHub Actions can run. Tests that cannot run on GitHub are waived, not release gates or follow-up tasks. Do not run local/browser/manual/device/live-cloud tests or request cloud credentials. Record waived tests as not run, never passed. Retain basic CI builds, signing and package/checksum inspection. See docs/task-overrides.md and docs/ci.md.
